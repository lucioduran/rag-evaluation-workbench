# Contributing

Keep changes focused and add a regression test for each corrected behavior.
Run the README testing commands and verify both recorded reports.

Never tune parameters, answer aliases, or prompts using the evaluation split.
A changed experiment contract requires a new version and separate recorded runs.
Do not overwrite evidence from a prior configuration. Document all deviations.

Keep all content in English without em dashes. Use sparse comments and separate
methodology documentation. Follow AGENTS.md and use small commits.
