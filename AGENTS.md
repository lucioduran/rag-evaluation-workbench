# Project rules

Follow ../AGENTS.md. Keep all repository content in English without em dashes.
Use focused commits and the configured Git identity. Add no assistant attribution.
Use only local hardware and free resources.

Complete this project before starting project 03. Release requires passing CI,
meaningful tests, real local model evaluation, raw results, confidence intervals,
error analysis, an MIT license, and the shared README structure.

Freeze the dataset, prompt, model revisions, and experiment configuration before
evaluation. Never tune on the evaluation split or replace failures with invented
results. Record changes and invalidate affected evidence when configuration changes.
